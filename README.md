# darave-releases
v1.2.3

Сетка пересчитывается в начале каждого стыка теперь. Точки и длина фраз считаются по структуре трека: события в минуту, смена бочки, снейрролл, вход басса, брейкдаун. Вокал идет отдельным слоем.
Techno/ house/ trance hiphop/big room/ 
dubstep/dnb/pop
Disco/funk
Industrial/metal
Вот эти ребята определяются все нормально.
Techno/ house/ trance - считаются не по стыкам, а по подъему или спаду внутри билда, соответственно у них другая логика сведения теперь.
жанровость как параметр вынес из анализа.
Keys/BPM теперь совмещаются не +0 +2 и sync долей с питчем, а по центам , которые пересчитывают keys в зависимости от смещения BPM - потому-что каждый стык теперь это отдельная сетка и bpm считается в ней от снейра внутри стыка. 
то есть теперь стоит еще меньше ориентироваться на Camelot/BPM/ENERGY треков при сведении 

так же добавлено панорамирование при унисоне.(когда 2 похожих источника звука конфликтуют создавая неприятные искажения из-за фазировки)
дабл вокал унисон так же разведен на фронт и бэк.
